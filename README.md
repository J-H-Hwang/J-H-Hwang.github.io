# j-h-hwang.github.io

Personal homepage of Jaehui Hwang. A single static page, no build step.

- `index.html`: the whole page. Publications are one list, newest release first. To add a paper,
  copy a `<div class="pub">` block to its place in that order and edit the title, authors, kind label
  (`k-j` Journal / `k-c` Conference / `k-p` Preprint), venue and links.
- `assets/profile.jpg`: profile photo. `CV_241209.pdf`: CV linked from the page.
- GitHub Pages serves the `master` branch root (`.nojekyll` turns off Jekyll).

Project pages live in their own repositories, e.g. https://j-h-hwang.github.io/np-opd/.
